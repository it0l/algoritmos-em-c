# Algoritmos em C

Coleção de exercícios e pequenos programas desenvolvidos durante o estudo de algoritmos e programação estruturada em C.

## Projetos

| Arquivo | Descrição |
| --- | --- |
| `BatalhaNaval.c` | Protótipo de batalha naval com posicionamento, validação e disparos em uma matriz 10 × 10 |
| `QUADRADOMAGICO.c` | Preenchimento e validação de um quadrado mágico 3 × 3 |
| `quadradoEspiral.c` | Geração de uma matriz quadrada preenchida em espiral |
| `codeAvaliacao/` | Exercícios de avaliação envolvendo matrizes, fatorial e vetores |

## Conceitos praticados

- funções;
- arrays e matrizes;
- laços e condicionais;
- validação de entrada;
- constantes;
- organização de problemas em etapas;
- manipulação de dados em memória.

## Compilando

Use um compilador compatível com C99 ou superior. Exemplo com GCC:

~~~bash
gcc BatalhaNaval.c -o batalha-naval
./batalha-naval
~~~

No Windows:

~~~powershell
gcc BatalhaNaval.c -o batalha-naval.exe
./batalha-naval.exe
~~~

Cada arquivo possui sua própria função `main` e deve ser compilado separadamente.
